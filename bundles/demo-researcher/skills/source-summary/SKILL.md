# Source Summary

Turn one source into a brief the reader can trust without re-reading it.

## Steps

1. Read the entire source. Note its title, author/owner, and date.
2. Extract, in the source's own terms:
   - the main claim or purpose (1 sentence),
   - the 3–5 load-bearing facts, each with the figure, name, or date
     exactly as the source states it,
   - any stated limitations, caveats, or dissent inside the source.
3. Write the brief:
   - **What it is** — one line: source, author, date.
   - **Key points** — one bullet per fact, each ending with a short
     quote or exact figure from the source in parentheses.
   - **Watch out** — caveats from step 2; if none, write "none stated".
4. If the source does not cover something the user asked about, say so
   explicitly at the end. Never fill gaps from general knowledge without
   labeling it as such.

## Rules

- No claim without a trace back to the text.
- Numbers and dates are copied character-for-character.
- Disagreement inside the source is reported, not resolved.
